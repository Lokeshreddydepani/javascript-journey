# JavaScript Developer Report Script

A lightweight JavaScript script demonstrating fundamental object manipulation, nested property access, dynamic property updates, and array iteration in Node.js.

## 📌 Concepts Covered
- **Nested Objects:** Accessing and structuring data cleanly.
- **Dynamic Property Mutation:** Updating and adding properties at runtime.
- **Array Traversal:** Iterating through skill lists using modern loops.
- **Formatted Logging:** Clean console output formatting.

## 🚀 How to Run

Make sure you have [Node.js](https://nodejs.org/) installed.

1. Clone or download this repository.
2. Open your terminal/command prompt in the project folder.
3. Run the script:

```bash
node developer_report.js
```

## 🛠 Tech Stack
- **Language:** JavaScript (ES6+)
- **Runtime:** Node.js
